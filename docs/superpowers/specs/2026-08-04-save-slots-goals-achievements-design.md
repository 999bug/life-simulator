# 存档槽位 + 目标成就 + 数据债 设计（第二弹）

日期：2026-08-04
状态：已批准

## 背景

节奏档位（第一弹）已完成。本弹推进剩余待办：多存档槽位与中途退出（第二弹）、人生目标与成就系统（第三弹）、数据债（adult_100 归类 + 0-2 岁事件补强）。用户选择全部一次做完。

## 模块 A：多存档槽位 + 中途退出

### 存储结构（useGame.ts 重构）

- 新 key `life-sim-saves-v2` = `{ active: number, slots: [SaveData | null, SaveData | null, SaveData | null] }`
- 旧存档迁移：首次启动检测 `life-sim-save-v1` 存在 → 迁入槽 0 → 删除旧 key（老玩家无感升级）
- 每步自动保存到 active 槽；继续人生 = 从选中槽恢复

### 标题页交互

- 存档卡片区：3 张卡片（名字/年龄/阶段，空的显示「空槽位」），点击卡片 = 设为 active 并继续该局；当前选中高亮
- 现有「继续人生」按钮改为卡片交互（删除旧按钮）
- 开始人生 → 覆盖选中槽（槽内有内容时弹确认，确认后覆盖）

### 中途退出

- GameScreen 右上角「✕ 退出」按钮 → 确认弹窗（自定义轻量模态，非 window.confirm）→ 回标题（存档保留在槽中）
- 结算页「重新开始」：语义从「清档」改为「保留存档在槽中」（槽位保留结局状态，开新局时覆盖）

### 布局约束

标题页新增卡片区后须复查 720px 溢出（第一弹修过，用紧凑卡片行布局避免复发）。

## 模块 B：人生目标 + 成就系统

### 人生目标（开局选择，6 个预设 + 无目标）

| 目标 | 达成条件（复用现有 flag/属性体系） |
|---|---|
| 💰 财富自由 | `wealth ≥ 80` 或 `startup_success` |
| ✈️ 环游世界 | `world_traveler` |
| 🎓 学术深耕 | `grad_school` 或 `top_university` |
| 🏥 白衣天使 | `doctor` |
| 🏠 家庭美满 | `married` + `has_child` + 幸福 ≥ 70 |
| ⚖️ 安稳一生 | `civil_servant` 或 `settled_down` |

- 选择时机：标题页「开始人生」→ 弹出目标选择模态（不占标题页版面）
- `goal` 字段进 GameState + 存档（旧存档无 goal → null）
- 结算页展示目标达成度：✅ 达成 / ❌ 未达成 + 差距提示（如「财富 65/80」）
- 达成判定为纯函数（引擎层，可单测）

### 成就系统（全局跨周目）

- localStorage key `life-sim-achievements`（数组存已解锁 id）
- 成就列表（12 个）：
  1. 出生：完成第一局
  2. 长寿：享年 ≥ 90
  3. 英年早逝：享年 < 40
  4. 财富自由：wealth ≥ 90
  5. 学霸：intelligence ≥ 85
  6. 事业有成：startup_success flag
  7. 环游世界：world_traveler flag
  8. 白衣天使：doctor flag
  9. 均衡发展：全属性 ≥ 60
  10. 精简通关：lite 模式走到结算
  11. 快速模拟：完成一局快速模拟
  12. 三局人生：累计完成 3 局
- 结算页：新解锁成就提示 + 成就面板（已解锁/未解锁，含描述）
- 标题页「🏆 成就」入口模态

## 模块 C：数据债

- adult_100（49 岁「知天命前夜」）：id 改为 4 位 `adult_0100`（归为模拟事件，与不在 keep-list 的事实一致）；`isMainlineEvent` 规则保持 2 位不污染
- 0-2 岁补事件：新增 3 个模拟事件（1 岁「第一次叫妈妈」、2 岁「蹒跚学步」「第一次发脾气」），走 chiled.json + clamp-effects + merge-fragments + build:events；0-2 岁密度 2 → 5

## 测试

## 风险

- 存档结构变更影响面大（迁移/active 槽/覆盖确认）——迁移逻辑必须单测覆盖
- 标题页元素继续增多（卡片区 + 成就入口）——720px 溢出是第一弹修过的，需复查
- adult_100 改 id 后旧存档 currentEventId 找不到该事件 → 兜底 null 顺延（既有机制，影响单事件）
